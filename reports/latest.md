## Les 5 meilleurs pour usage réel

- Prototypage rapide d'applications IA avec des API LLM gratuites (Google Gemini AI Studio, Groq, Mistral API Expérimental).
- Tests et développement local sans coût avec Ollama.
- Exploration de modèles et expérimentation sur Hugging Face Hub.
- Démarrage de projets cloud avec des crédits startup généreux (AWS Activate, Google Cloud for Startups).
- Développement de code assisté par IA avec des niveaux gratuits (GitHub Copilot Free, Gemini Code Assist).

## Les 5 plus risqués / instables

- Les crédits startup des grands fournisseurs cloud (AWS, Google, Azure) peuvent avoir des conditions d'éligibilité strictes et des dates d'expiration.
- Les free tiers API (OpenAI, Mistral) ont des limites de taux qui peuvent rapidement devenir un goulot d'étranglement pour la production.
- Les programmes de crédits gratuits ponctuels (ex: OpenAI Codex) sont sélectifs et limités dans le temps.
- Les offres de parrainage (RunPod) ont des bonus aléatoires et dépendent de l'activité d'autres utilisateurs.
- Les offres 'US-only' exceptionnelles, si elles existent, sont exclues par défaut sauf si explicitement mentionnées.

## À surveiller de près

- Surveiller les mises à jour des programmes de crédits cloud pour startups, car les montants et conditions évoluent.
- Garder un œil sur les nouveaux fournisseurs d'inférence offrant des niveaux gratuits ou des crédits d'essai généreux.
- Suivre les annonces de Mistral AI concernant les évolutions de leur plateforme 'La Plateforme' et leurs offres API.
- Explorer les programmes de crédits spécifiques pour les startups IA émergentes (ex: Bright Data).
- Rester informé des évolutions des free tiers des API LLM majeures (Google Gemini, Groq) pour les limites et les modèles disponibles.

## Les 5 meilleurs pour usage réel

- Prototypage rapide d'applications LLM avec Groq (API rapide et gratuite pour les modèles open-source).
- Expérimentation de charges de travail GPU avec les crédits gratuits de RunPod ou Lambda Labs.
- Test de différents modèles d'inférence via l'API Replicate (avec des runs gratuits limités).
- Développement d'applications IA sur des plateformes cloud majeures (GCP, Azure) grâce à leurs crédits de bienvenue.
- Exploration de modèles open-source et déploiement d'applications ML sur Hugging Face.

## Les 5 plus risqués / instables

- CoreWeave Trial Credits (soumis à approbation et contexte business).
- OpenAI API Free Credits (programmes étudiants/développeurs, non garantis et variables).
- Vast.ai (fiabilité variable selon les fournisseurs, interruptions possibles des instances spot).
- Replicate Free Runs (limités, nécessitent une configuration de facturation rapidement).
- Les offres de crédits GPU pour les startups (RunPod Startup Program, CoreWeave Accelerator) nécessitent souvent un statut de startup validé ou un engagement financier.

## À surveiller de près

- Modal Free Tier ($30/mois) : Excellent pour les cas d'usage serverless GPU.
- Cloudflare AI Gateway : Intéressant pour l'optimisation des appels API Replicate, mais le coût réel reste chez Replicate.
- Les programmes de crédits étudiants/développeurs (OpenAI, Google, Azure) : à surveiller pour les mises à jour et les montants.
- Les offres de crédits GPU pour les startups (RunPod, CoreWeave) : potentiellement très intéressantes si le profil correspond.
- Les nouvelles offres de fournisseurs GPU cloud émergents (ex: Together AI, Fireworks AI, si des free tiers ou crédits d'essai apparaissent).

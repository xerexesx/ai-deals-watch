## Les 5 meilleurs pour usage réel

- Prototypage rapide d'applications LLM avec des free tiers généreux (Google Gemini, Groq).
- Expérimentation GPU à bas coût pour l'entraînement ou l'inférence (Vast.ai, RunPod, Modal).
- Intégration de modèles ML spécialisés via API (Hugging Face).
- Développement d'agents IA sur une infrastructure cloud stable et gratuite (Oracle Cloud Free Tier).
- Comparaison et test de multiples LLM via une interface unique (OpenRouter).

## Les 5 plus risqués / instables

- AWS Free Tier : risque élevé de facturation surprise si les quotas ne sont pas gérés activement.
- RunPod Referral Bonus : montant aléatoire et dépôt initial requis, moins fiable pour une planification budgétaire.
- Together AI Startup Accelerator : application requise, durée de vie limitée des crédits, non garanti pour tous.
- Hugging Face Inference API : pas de SLA garanti, performance potentiellement inconsistante sur le tier gratuit.
- Vast.ai : marché décentralisé, la fiabilité et la disponibilité peuvent varier.

## À surveiller de près

- Anthropic API : offre des crédits d'inscription ($5) mais pas de free tier permanent. À surveiller pour d'éventuelles nouvelles offres.
- OpenAI API : crédits d'inscription limités ($5-$18), pas de free tier permanent. L'accès aux modèles les plus récents est payant.
- Fireworks AI : offre des crédits pour les startups, mais les détails du free tier ne sont pas clairs.
- Replicate AI : offre des crédits limités pour les modèles communautaires, mais pas de free tier robuste.
- Cloudflare Workers AI : potentiel intéressant, mais les détails des offres gratuites pour les développeurs solo sont à clarifier.
